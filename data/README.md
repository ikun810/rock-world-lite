# 固定运行资料

本目录对应 Lite v0.11.0 / `m1-close-20261030-v1`。

- `runtime-map.json`：沿用已验收的地图与通行规则资料。
- `catalog-names.json`：沿用名称查询目录。
- `character-book.json`：v0.11.0 角色卡绑定世界书的固定参考内容。
- `character-book-v0.10.0.json`：保留 v0.10.0 角色卡自己的固定参考书，使旧角色和聊天可继续使用。

扩展根据角色卡发行版本选择对应参考书，并核对完整内容摘要。玩家存档保存在浏览器 IndexedDB 中，不位于本目录。更新运行文件和资料后刷新页面。
