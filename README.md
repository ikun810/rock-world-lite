# 洛克世界 Lite — SillyTavern 扩展

版本 **0.10.0**，对应《洛克王国·世界模拟器》Lite 的 M1-05 交付。

为配套角色卡提供世界书绑定、地图移动与计时、源点激活/传送、家园往返和浏览器本机存档。运行文件已经构建完成，安装后无需运行 npm 或手动编译。

## 通过 Git 仓库安装

安装地址：

```text
https://github.com/ikun810/rock-world-lite
```

1. 复制上面的仓库地址。
2. 在 SillyTavern 打开 **扩展 → 安装扩展（Install extension）**，粘贴仓库地址并安装；分支使用默认值。
3. 刷新页面，在扩展管理中确认 **洛克世界 Lite** 已启用。
4. 导入配套的 `rock-world-Lite-v0.10.0.json` 角色卡并打开它。如果酒馆询问导入内嵌世界书，选择 **No／否**，由扩展核验并建立绑定书。
5. 等待状态栏出现“已保存”，输入 `/rock 状态` 或 `/rock 帮助`。

角色卡是单独的交付文件。此仓库提供扩展运行文件，角色卡需要另外导入。

### 已经手动安装过 ZIP

先在需要保留的聊天执行 `/rock 导出`。将旧 `rock-world-lite` 目录移到 SillyTavern 的扩展目录之外，刷新后再通过仓库地址安装。不要在用户扩展与全局扩展目录同时保留两份；已有同名目录会导致 Git 安装返回目录冲突。

### 更新

之后可在 SillyTavern 的扩展管理中检查并更新本扩展，更新后刷新页面。更新前先导出需要保留的存档。仅在配套版本说明要求时更换角色卡和世界书；本次 Git 发布的运行文件与已经交付的 v0.10.0 ZIP 完全一致。

## 常用命令

| 命令 | 用途 |
|---|---|
| `/rock 状态` | 查看已保存位置和游戏时间 |
| `/rock 帮助` | 查看当前支持的操作 |
| `/rock 前往学院驻地` | 按大地图坐标步行并结算时间 |
| `/rock 激活魔力之源` | 激活已到达的源点 |
| `/rock 传送至学院驻地` | 传送到已激活的源点 |
| `/rock 回家`、`/rock 离家` | 家园往返 |
| `/rock 导出`、`/rock 导入` | 导出存档或导入到独立新聊天 |

## 运行环境与当前范围

- 实际验收基线为 SillyTavern 1.19.0；后续客户端版本和插件组合需按实际兼容结果确认。
- 使用浏览器 Web Crypto、IndexedDB 和 SillyTavern 原生接口。
- 普通大陆区块边缘自由通行，按大地图距离计时；进入独立魔法学院检查已保存的风眠省主线完成条件。
- 当前开放移动、源点、学院转换和家园操作。捕捉、制作与剧情奖励尚未开放。
- 游戏时间随行动推进，离线不补时间。
- 存档属于当前浏览器与站点；更换设备、浏览器、域名或端口前使用导出/导入。

详细安装、世界书配置与卸载步骤见 [INSTALL.md](INSTALL.md)，存档迁移与备份说明见 [SAVE-TRANSFER.md](SAVE-TRANSFER.md)。

## 发布文件

`manifest.json`、`index.js`、`runtime.js` 与 `data/` 位于仓库根目录，供 SillyTavern 的 Git 安装器直接发现。`SHA256SUMS` 记录本发布目录的文件摘要。

本次发布沿用 M1-05 的运行文件与版本，不改变游戏规则或存档格式。酒馆助手与 ST-Prompt-Template 已作为项目后续开发参考，当前版本尚未集成这两项扩展。
