# 洛克世界 Lite v0.11.0 — 姓名、行动时钟与旧档衔接

**扩展安装／更新地址：[https://github.com/ikun810/rock-world-lite](https://github.com/ikun810/rock-world-lite)，分支 `main`。**

**新聊天角色卡：[下载 rock-world-Lite-v0.11.0.json](https://github.com/ikun810/rock-world-lite/raw/refs/heads/main/rock-world-Lite-v0.11.0.json)。**

本版完成 M1-01 的基础状态、姓名与受限旧档迁移，以及 M1-03 的交谈、等待和快进计时。已有 v0.10.0 角色卡继续支持；延续原进度时，更新扩展后打开原角色、原聊天即可。

## 已在使用 v0.10.0：这样更新

1. 在要保留的原聊天输入 `/rock 导出`，留一份更新前存档。
2. 在 SillyTavern 的扩展管理中更新 **洛克世界 Lite**，然后刷新页面。
3. 打开原来的 v0.10.0 角色和聊天。存档会自动升级，**原有位置、累计游戏时间和历史记录保留，升级本身为 0 分钟**。
4. 输入 `/rock 状态` 查看已保存的姓名、位置和时间。升级提示中会给出 `/rock 备份 v010-…`，复制完整命令即可下载升级前原始快照。

恢复备份时使用 `/rock 导入` 选择文件；扩展会创建独立新聊天，原聊天继续保留。已经采用文件目录安装的用户，按 [安装与更新](https://github.com/ikun810/rock-world-lite/blob/main/INSTALL.md) 更新原目录或转为 Git 安装。

v0.11.0 新卡用于新聊天。导入新卡会产生新的角色实例；**新头像／角色实例不会自动继承旧角色的本机存档**。希望在新卡下续玩时，先在旧聊天导出，再在新卡角色下执行 `/rock 导入`。

## 第一次安装

在 **扩展 → 安装扩展** 粘贴上方仓库地址，安装后刷新，再导入 v0.11.0 JSON 角色卡。如果酒馆询问是否导入内嵌世界书，选择 **No／否**，由扩展核验并建立对应书。状态栏显示“姓名 · 位置 · 游戏分钟 · 已保存”后即可操作。完整步骤见 [INSTALL.md](https://github.com/ikun810/rock-world-lite/blob/main/INSTALL.md)。

运行文件已构建完成，玩家无需安装 Node、Python、酒馆助手、ST-Prompt-Template、MVU、SkyUI 或 Extras。本版沿用 SillyTavern 原生接口与浏览器本机存储。

## 姓名与时间命令

默认姓名为 **小洛克**。开场可以命名；首次有效游戏行动后姓名锁定。v0.10.0 存档升级后补入默认姓名，可在下一次游戏行动前设置；完整 v0.9 旧档导入则保留原姓名。

| 输入示例 | 行为 | 游戏时间 |
|---|---|---:|
| `/rock 开场姓名 晨风`、`/rock 姓名 晨风`，或单独发送 `我叫晨风` | 保存开场姓名；行动后不能再改 | 0 分钟 |
| `/rock 交谈` | 明确结算一次抽象交谈 | 1 分钟 |
| `交谈：你好`、`说：你好` | 明确发起一次交谈，后续模型对话正文保留 | 1 分钟 |
| `/rock 等待`，或单独发送 `等待` | 自然等待，未写时长时默认一分钟 | 1 分钟 |
| `/rock 等待10分钟` | 按明确时长等待 | 10 分钟 |
| `/rock 快进1小时` | 按明确时长快进 | 60 分钟 |
| `/rock 状态`、`/rock 帮助`、普通未标记聊天、OOC 提问 | 查询或聊天，不自动结算时间 | 0 分钟 |
| `/rock 重试` | 复用上一玩家意图；已提交动作不重复计时 | 不重复增加 |
| `/rock 导出`、`/rock 导入`、`/rock 备份 备份ID` | 导出当前存档、导入到新聊天、下载原文备份 | 0 分钟 |

指定等待和快进支持正整数 **分钟／小时／天**，换算后每次最多 **43200 分钟（30 天）**。快进必须明确写出时长；模型不能因剧情写着“等待几天”而自行跳过时间，也不能借此完成主线或发放奖励。

交谈在玩家行动被接受并保存时计时，不等待模型回复。后续生成、取消回复、重生成或切换回答都不会为同一行动再计一分钟。引用命令、OOC、模型输出或裸 `RW_ACTION` 标签不能自行授权时间变化。

## 原有玩法与世界书

大地图步行、探索、源点显式激活／传送、学院转换、回家和离家沿用原规则。普通大陆地表双向通行；进入独立魔法学院仍要求已保存的风眠省主线完成条件。步行按实际距离计时；激活、传送、学院转换与家园往返为 0 分钟。离线不补时间。

人物目前只保存姓名；背包、关系、宠物、剧情和家具容器预留为空。捕捉、制作和任务奖励尚未开放，角色卡背景不会授予这些权限。

| 角色卡 | 严格绑定的世界书 |
|---|---|
| v0.10.0，已有聊天继续使用 | 洛克世界 Lite 0.10.0 · 1988d1bc9957 |
| v0.11.0，新聊天使用 | 洛克世界 Lite 0.11.0 · a5f56de75282 |

两版分别核对完整固定内容；新书不会覆盖旧书，同名但不同内容的书会阻止结算。每版保留完整 893 条来源与契约记录；不要在同一聊天重复加载两个版本的书。

## 存档与旧地图

存档按当前浏览器、站点、账户、角色实例和聊天分支隔离。换设备、浏览器配置文件、域名或端口前使用导出／导入；服务器聊天文本不等于本机游戏存档。

旧地图只接受魔法师之家、月牙湖岸、家园区域的八种明确位置形式，或包含该位置的受限 v0.9 完整存档。未知地点、坐标冲突和不支持的进度会拒绝；只有原文备份写入并读回成功后才继续验证，不会猜坐标或默默重置。支持表和恢复步骤见 [SAVE-TRANSFER.md](https://github.com/ikun810/rock-world-lite/blob/main/SAVE-TRANSFER.md)。

历史分支恢复所选消息当时的检查点；重命名继续原存档。修改、删除历史消息不会倒转世界。复制原生聊天 JSONL 不能代替 `/rock 导出` 与 `/rock 导入`。
